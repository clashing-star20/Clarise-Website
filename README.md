# Clarise Faustino — Static Website

This is a simple, responsive static site for Clarise G. Faustino. It's ready to be published on GitHub Pages.

Files added:

- `css/styles.css`

Quick deploy (GitHub Pages):

1. Create a new repository named `USERNAME.github.io` where `USERNAME` is your GitHub username.
2. Commit and push the files to the repository's `main` branch.

Example commands:

```bash
git init
git add .
git commit -m "Add Clarise Faustino website"
git branch -M main
git remote add origin git@github.com:USERNAME/USERNAME.github.io.git
git push -u origin main
```
